# Knowledge Graph

This section captures relationships between systems, repos, business flows, databases, APIs, and messaging.

## Purpose

The knowledge graph is not a graph database. It is a set of Markdown nodes plus relationship metadata that agents can traverse.

## Current status

- This repository contains the entry point for the knowledge graph.
- Relationship files and node docs should be added as evidence becomes available.

## Next actions

- Define node types for systems, repos, databases, APIs, messages, and flows.
- Add relationship metadata files such as `ownership.yaml` and `dependencies.yaml`.
- Keep node docs small and linkable.
