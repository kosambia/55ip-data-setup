# Architecture

This section captures the system architecture and high-level component inventory.

## Goals

- Describe the architecture model used by the repository.
- Capture architecture decisions in a lightweight, agent-readable format.
- Link architecture documentation to database and flow docs.

## Current architecture view

- `docs/system-overview.md` contains the top-level system description.
- `docs/data/index.md` will contain database schema and table inventories.
- `docs/business-flows/index.md` will capture end-to-end business flows.
- `docs/knowledge-graph/index.md` will capture relationships between systems, repos, data, and flows.

## Architecture notes

This repository is intentionally generic and agent-driven. It should be updated as system evidence becomes available.
