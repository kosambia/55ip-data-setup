## How to use this repo

1. Start at `AGENTS.md`.
2. Use `docs/index.md` to navigate the documentation.
3. Run `scripts/generate_pg_docs.py` to populate database docs from a PostgreSQL instance.
4. Use the spec files in `docs-specs/` to drive updates.
