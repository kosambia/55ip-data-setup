# Repository Index

This index lists all repositories that make up the 55ip data setup ecosystem.

## Modules in this Monorepo
- `55ip-client`: Manages Financial Advisor and Investor relationships.
- `55ip-portfolio`: Manages investment accounts, portfolios, and holdings.
- `55ip-tax`: Manages tax-loss harvesting rules and transitions.
- `55ip-trade`: Trade operations and execution rules.
- `55ip-core`: Shared utilities.
- `55ip-db`: Database schemas, migrations, and mock data.
