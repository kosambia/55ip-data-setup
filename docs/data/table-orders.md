# Orders Table

## `orders` Table
Tracks market and limit orders generated by the 55ip system, before they are executed into trades.

### Schema
- `order_id` (BIGSERIAL, PK)
- `account_id` (BIGINT, FK -> `account`)
- `strategy_id` (BIGINT, FK -> `model_strategy`)
- `symbol` (TEXT, NOT NULL)
- `side` (TEXT, NOT NULL) - IN ('BUY', 'SELL')
- `order_type` (TEXT, NOT NULL) - IN ('MARKET', 'LIMIT')
- `tif` (TEXT, NOT NULL) - IN ('DAY', 'GTC', 'IOC', 'FOK'), Default 'DAY'
- `order_status` (TEXT, NOT NULL) - IN ('OPEN', 'PARTIALLY_FILLED', 'FILLED', 'CANCELLED', 'REJECTED')
- `requested_quantity` (NUMERIC(18,6), > 0)
- `filled_quantity` (NUMERIC(18,6), Default 0)
- `limit_price` (NUMERIC(18,4))
- `avg_fill_price` (NUMERIC(18,4))
- `principal_amount` (NUMERIC(18,2))
- `tax_impact_estimate` (NUMERIC(18,2))
- `created_at` (TIMESTAMPTZ)
- `submitted_at` (TIMESTAMPTZ)
- `filled_at` (TIMESTAMPTZ)
