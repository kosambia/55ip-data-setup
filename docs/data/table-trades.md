# Trades Tables

## `trades` Table
Records executed trades that change position quantities and open/close tax lots.

### Schema
- `trade_id` (BIGSERIAL, PK)
- `account_id` (BIGINT, FK -> `account`)
- `strategy_id` (BIGINT, FK -> `model_strategy`)
- `position_id` (BIGINT, FK -> `positions`)
- `symbol` (TEXT, NOT NULL)
- `side` (TEXT, NOT NULL) - IN ('BUY', 'SELL')
- `quantity` (NUMERIC(18,6), > 0)
- `price` (NUMERIC(18,4), > 0)
- `counterparty` (TEXT, NOT NULL)
- `trade_date` (DATE, NOT NULL)
- `created_at` (TIMESTAMPTZ)
- `updated_at` (TIMESTAMPTZ)

## `trade_list` Table
Contains proposed or intended trades before execution, often generated by the tax-aware rebalancing engine.

### Schema
- `trade_list_id` (BIGSERIAL, PK)
- `order_id` (BIGINT, FK -> `orders`)
- `position_id` (BIGINT, FK -> `positions`)
- `account_id` (BIGINT, FK -> `account`)
- `strategy_id` (BIGINT, FK -> `model_strategy`)
- `symbol` (TEXT)
- `side` (TEXT) - IN ('BUY', 'SELL')
- `reason_code` (TEXT)
- `priority_rank` (INTEGER)
- `target_weight_before` (NUMERIC(9,6))
- `target_weight_after` (NUMERIC(9,6))
- `quantity_to_trade` (NUMERIC(18,6))
- `estimated_trade_value` (NUMERIC(18,2))
- `tax_aware_flag` (BOOLEAN)
