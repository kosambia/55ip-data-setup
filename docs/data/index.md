# Database Index

Index of all databases, schemas, and critical tables for 55ip data setup.

## Databases

### Portfolio DB
- **Engine**: PostgreSQL
- **Host**: `127.0.0.1:5432`
- **Owner**: `data-engineering-team`
- **Description**: Core system of record for 55ip wealth management operations. Stores portfolios, tax rules, constraints, and trading orders.
- **Important Tables**: 
  - `account`: Client account definitions. See [Account Schema](table-account.md)
  - `model_strategy`: Investment strategies. See [Model Strategy Schema](table-model-strategy.md)
  - `positions`: Account holdings. See [Positions Schema](table-positions.md)
  - `trades` & `trade_list`: Order executions. See [Trades Schema](table-trades.md)
  - `tax_lot`: Cost basis and wash sale tracking. See [Tax Lot Schema](table-tax-lot.md)
  - `orders`: Trade orders generated by the platform. See [Orders Schema](table-orders.md)

### Tax DB
- **Owner**: `quant-team`
- **Description**: Stores tax rules, limits, and harvesting metrics.
- **Important Tables**: `tax_rules`, `harvesting_events`.
